# Submission guide — all 28 tasks

Replace `<USER>` with your GitHub username and `<REPO>` with your repository name.

## 1. Push to GitHub (public repo)
```bash
cd cars-dealership-capstone
git init && git add . && git commit -m "Cars Dealership capstone"
git branch -M main
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```
Pushing triggers the **CI** workflow (Actions tab).

## 2. Generate the text evidence (real output from your own machine)
```bash
pip install -r requirements.txt
bash evidence/generate_evidence.sh
```
This starts the server, calls every API and writes these files into `evidence/`:
`django_server`, `loginuser`, `logoutuser`, `getdealerreviews`, `getalldealers`, `getdealerbyid`,
`getdealersbyState`, `getallcarmakes`, `analyzereview`. Open each file, copy its full text into the answer box.

## Tips
- Screenshots must show your own running app and the browser address bar. Do them in the order above.
- For Tasks 5-6 the script logs in as `demo` and then logs out with the saved session cookie.
- To test the deployed site's API with the same script: `BASE_URL=https://your-app.onrender.com bash evidence/generate_evidence.sh`.
- Check the About page: change the names/emails to your own details if your course expects personal information.
